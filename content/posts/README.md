# Publicações do blogue

Esta pasta é editada pelo Pages CMS. Cada publicação deve ser um arquivo Markdown com frontmatter YAML.

Arquivos com `draft: true` são rascunhos e não entram na geração das páginas públicas, da listagem nem da busca local. Ainda assim, se forem enviados ao repositório público, continuam acessíveis pelo GitHub.

Os textos do WriteFreely permanecem como links externos no conteúdo do site. Não copie textos para cá sem decisão editorial e autorização correspondente.
